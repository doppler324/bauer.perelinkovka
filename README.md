# Модуль «Перелинковка» (bauer.perelinkovka) для 1С-Битрикс

Две независимые части в админке (Сервисы → Перелинковка):

1. **Перелинковка блоков** — блоки-правила (откуда → куда, лимит ссылок, порог, стратегии подбора, равномерность),
   список связей (ручное и массовое добавление), статистика входящих ссылок. Выводит связи компонент `bauer:perelinkovka.links`.
2. **Перелинковка внутри текстов** — расстановка ссылок-анкоров в `DETAIL_TEXT` статей: по одной статье, по разделу,
   по всему инфоблоку; синонимы; настройки; прогресс-бары, отмена расстановки (исходный текст хранится в таблице модуля).

## Требования
PHP 8.0+, UTF-8 (`BX_UTF`), модуль `iblock`, расширения `dom` и `mbstring`.

## Установка
1. Склонируйте репозиторий прямо в папку модулей (корень репозитория и есть модуль):
   `cd local/modules && git clone https://github.com/doppler324/bauer.perelinkovka.git bauer.perelinkovka`
   (или в `/bitrix/modules/`). Обновление: `cd local/modules/bauer.perelinkovka && git pull`.
2. Админка → Настройки → Настройки продукта → Модули → «Перелинковка» → Установить.
3. Сервисы → Перелинковка: создайте блок, нажмите подбор связей; на странице разместите компонент:

```php
$APPLICATION->IncludeComponent('bauer:perelinkovka.links', '', [
    'BLOCK_CODE' => 'similar', 'ENTITY_TYPE' => 'element', 'ENTITY_ID' => $arResult['ID'],
]);
```

Шаблоны компонента: `.default` (карточки) и `list`; для своего дизайна скопируйте шаблон в `/local/templates/<сайт>/components/bauer/perelinkovka.links/`.

## Как это работает
* Таблицы: `b_bauer_perelinkovka_block` (блоки), `_link` (связи), `_anchor` (тексты статей: исходный и со ссылками).
* Адреса ссылок берутся из настроек инфоблока (`DETAIL_PAGE_URL`, `SECTION_PAGE_URL`).
* Ключевые слова — из свойства (код задаётся в настройках модуля, по умолчанию `KEYWORDS`).
* Агент пересчитывает активные блоки порциями (интервал в настройках модуля).
* Настройки анкоров и синонимы хранятся в `b_option`.
* Тексты со ссылками записываются в `DETAIL_TEXT` элемента; «Отменить» возвращает исходный.

## Разработка и тесты без Битрикса
`php -S localhost:8000 -t tests`, затем `admin_preview.php` (предпросмотр) или `module_shell.php` (боевая оболочка на JSON-данных).
Стили: `python3 dev/build/scope_css.py` собирает `install/css/admin.css` (стили ограничены областью `#bp-app`).
После правок в `install/css`, `install/js`, `install/components` переустановите модуль (удалить → установить), чтобы файлы скопировались в `/bitrix/`.
Планы и архитектура — в `dev/plans`. Правки админки вносятся в `admin/tabs/*` — они общие для тестового и боевого режима.
